# Security Policy

## Supported Versions

Security reports are currently handled against the latest `main` branch state.
If you can reproduce an issue on top of `main`, include that detail in the
report.

## Reporting A Vulnerability

Please use GitHub Private Vulnerability Reporting:

<https://github.com/tuxerrante/dot-config-nvim/security/advisories/new>

Please do not open a public GitHub issue for a security problem.

Useful report details:

- the affected feature, command, or plugin integration
- reproduction steps
- whether the issue depends on untrusted repo content, shell commands, or
  copied secrets
- Neovim version, OS, and any relevant tool versions
- impact, especially if the bug could expose tokens, files, or local command
  execution

I will triage the report privately and use the normal GitHub advisory flow for
fix coordination and disclosure timing.
